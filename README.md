# Zsena — portfolio / online CV

Source code for my lightweight static portfolio and online CV.

## Planned GitHub Pages URL

```text
https://zsena.github.io/
```

## Stack

- Semantic HTML
- Modern CSS
- Small vanilla JavaScript theme toggle
- No framework or build step required

## Local preview

Open `index.html` directly in a browser, or run any simple static HTTP server.

## Publishing

For a user-level GitHub Pages site, this repository should be named:

```text
Zsena.github.io
```

and be public with GitHub Pages enabled from the default branch.
